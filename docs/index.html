Turn a Waveshare ESP32-S3 2.8″ board into a small wireless Android Auto screen that shows the Google Maps view from your phone. Hardware, flashing, phone setup and daily use, step by step.

0How it works

No app on the phone, no Bluetooth, no extra hardware.

Android Auto always runs on the phone: the phone draws the Maps screen and streams it as video to a car's screen (the head unit), which only displays it and sends back touches. MiniNav plays the part of that car screen. Android Auto has a hidden developer option, Start headunit server, that lets a head unit connect to the phone over WiFi; MiniNav connects to it, completes the Android Auto handshake (TLS), receives the H.264 video of the Maps screen and decodes it on the ESP32-S3.

2Flash the firmware

Straight from the browser: nothing to install, about one minute.

  1. Use Chrome or Edge on a computer (they can talk to USB devices; Safari and Firefox can't).
  2. Plug the board into the computer with a USB-C data cable.
  3. Click Install MiniNav and pick the board's port (named like USB JTAG/serial debug unit, usbmodem or COM5). The page erases what's needed, writes the firmware at the right address and checks it.

    Details
  4. When it says done, the board restarts and shows the boot animation, then the connection screen. If the screen stays black, unplug the board and plug it back in.
If the port doesn't show up or flashing can't connectUse a data cable (some only charge). Hold BOOT, tap RESET, release BOOT, then click Install again. After flashing in this mode, tap RESET once.
Default WiFi namesThis firmware uses hotspot MiniNavHotspot, board WiFi MiniNav, password mininav123 for both, and right-hand drive. To change them, build from source instead.
Flash the file by hand instead
  1. Download MiniNav.bin.
  2. Open espressif.github.io/esptool-js in Chrome or Edge.
  3. Click Connect and pick the board's port. The file picker only appears after this.
  4. Change Flash Address from the default 0x1000 to 0x0 (the ESP32-S3 starts at 0; at 0x1000 the screen stays black), choose MiniNav.bin, then click Program.
  5. Tap RESET when it finishes.

3Set up the phone (once)

Unlock Android Auto's developer settings and start its headunit server.

  1. Update Android Auto from the Play Store.
  2. Open Android Auto settings: Settings → Connected devices → Android Auto (or search "Android Auto").
  3. Scroll to the bottom and tap Version 10 times, then confirm. Developer settings are now unlocked.
  4. Tap the ⋮ menu (top right) → Start headunit server. A notification shows it is running.
  5. Set Android Auto's battery usage to Unrestricted (Settings → Apps → Android Auto → Battery), so it keeps running with the screen off.

4Connect the phone and the board

The board offers two ways at the same time. Use A unless you have a reason not to.

  1. On the phone: Settings → Connections → Mobile Hotspot (names vary by brand).
  2. Name it MiniNavHotspot, password mininav123 (or what you set in menuconfig), band 2.4 GHz.
  3. Turn the hotspot on. If the phone ever joined MiniNav, tap it in the WiFi list → Forget.
  4. Power the board. Within ~10 s it joins the hotspot and finds Android Auto.
  1. Power the board, then on the phone join WiFi MiniNav, password mininav123, and allow auto-reconnect.
  2. When the phone says the network has no internet, choose to stay connected.
  3. Turn off "WiFi assistant" / "Switch to mobile data" if the phone keeps leaving MiniNav.
Heads upSome phones (seen on Samsung) stop using mobile data while joined to a WiFi without internet, so Maps can't search. If that happens, use mode A.

5Ride or drive

  1. Plug the board into the USB port on your bike or in your car. It boots in under a second (the animation plays while WiFi starts).
  2. Turn on the phone hotspot (mode A). Check the headunit server notification is still there.
  3. Start navigation in Google Maps on the phone (or by voice), then lock the phone and put it away.
  4. The map appears on the board. Mount it where you can glance at it.

6Print the case

Two parts, in docs/case/. The back panel has slits for a strap, so you can tie it to handlebars or a mount.

No 3D printer?Upload both STL files to a printing service such as Robu.in's 3D printing service; the case costs about ₹100–200. Ask for PETG.

  1. Open both STL files in your slicer (PrusaSlicer, Bambu Studio, Cura…).
  2. Material: PETG or ASA for a bike or car (PLA softens in the sun). 0.2 mm layers, 3 walls, 15–20 % infill.
  3. Orient each part as in the table; add supports only if your slicer flags overhangs.
  4. Fit the board, check the USB-C port and BOOT button line up, then close the case.
